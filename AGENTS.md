# Rules

## Button Colors
- Primary action buttons must use the brand teal color: `bg-[#00B4B6] hover:bg-[#008B8E] text-white`
- This applies to all primary CTAs across the app: "Registrar Venta", "+" add to cart, "Nuevo Producto", "Guardar", "Crear", etc.
- Secondary/outline buttons should use shadcn's `variant="outline"` (no brand color override).
